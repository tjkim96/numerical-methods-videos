Numerical Methods, video by video

This site mirrors the Canvas shell for ME 2004 — Engineering Analysis: Numerical Methods (Summer 2022), taught by Jaisohn Kim, so that anyone in the world can follow the same reading-and-lecture schedule the class used — in the order it was designed to be watched.

Every lecture links out to Jaisohn's YouTube channel, @jaisohnkim, which hosts the full video library of MATLAB and numerical-methods tutorials.

How to use this site

  1. Pick a week below (there are six, covering MATLAB fundamentals through ODEs).
  2. For each day, do the listed readings first, then watch the lectures in order — most videos are split into short (1/2), (2/2)/(1/3)…(3/3) segments.
  3. The schedule is a suggestion, not a strict deadline — pace yourself across the week.
